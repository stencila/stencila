Refresh the official trust-list cache

# Usage

```sh
stencila credentials trust refresh [OPTIONS]
```

# Options

| Name       | Description                                                               |
| ---------- | ------------------------------------------------------------------------- |
| `-a, --as` | Output format. Defaults to text. Possible values: `json`, `yaml`, `toml`. |
